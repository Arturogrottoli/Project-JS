¿Por Qué Objetos Literales?

Fundamentos

Hasta ahora usamos variables sueltas y arrays. Pero, ¿qué pasa cuando necesitamos representar algo más complejo, como un usuario o un producto?

  • El problema: variables sueltas como marca, modelo y year no le dicen a JavaScript que pertenecen al mismo auto.
  • Un objeto agrupa valores relacionados bajo un solo nombre, usando llaves {}.
  • A diferencia de los arrays (por posición/índice), los objetos acceden a los datos mediante nombres o claves.
// Variables sueltas (el problema) let marca = "Toyota" let modelo = "Corolla" let year = 2022 // Nada indica que pertenecen al mismo auto

La Anatomía de un Objeto

Sintaxis Core

Un objeto literal es la forma más directa de crear un objeto en JavaScript, utilizando llaves {}.

  • usuario es el nombre de nuestro objeto.
  • nombre, edad, ciudad son las claves (keys) o etiquetas.
  • "Ana", 25, "Madrid" son los valores (values).
  • Cada combinación de clave y valor se denomina propiedad.
const usuario = { nombre: "Ana", edad: 25, ciudad: "Madrid" }

Propiedades: Los Datos del Objeto

Ejemplo E-commerce

Las propiedades son como variables que viven dentro del objeto: strings, números, booleanos, e incluso arrays u otros objetos.

  • Un producto no es solo un nombre: es un conjunto de datos heterogéneo.
  • Agrupar esta información en una sola entidad hace el código más organizado y fácil de entender.
const producto = { id: "A152", nombre: "Auriculares Bluetooth", precio: 59.90, enStock: true, coloresDisponibles: ["Negro", "Blanco", "Azul"] }

Métodos: El Comportamiento del Objeto

La Palabra Clave this

Cuando guardamos una función dentro de una propiedad, esa función pasa a llamarse método.

  • Los métodos representan acciones que el objeto puede realizar. Se ejecutan con paréntesis: persona.presentarse().
  • this hace referencia al objeto mismo: permite que un método use los propios datos del objeto.
const persona = { nombre: "Carlos", presentarse: function() { console.log("Hola, mi nombre es " + this.nombre) } } persona.presentarse() // Hola, mi nombre es Carlos

Acceso a la Información: Punto vs Corchetes

Dos Herramientas

Para leer, modificar o crear propiedades, tenemos notación de punto y notación de corchetes.

  • Punto (.): la más común, cuando sabemos el nombre de la propiedad de antemano.
  • Corchetes ([]): obligatorio si el nombre tiene espacios/caracteres especiales, o si está guardado en una variable.
console.log(producto.nombre) // "Auriculares Bluetooth" producto.precio = 55.00 // Modificamos el valor const propiedadABuscar = "nombre" console.log(producto[propiedadABuscar]) // "Auriculares Bluetooth" // producto.propiedadABuscar daría undefined

Manipulación de Objetos: Agregar y Eliminar

Objetos Dinámicos

Los objetos en JavaScript son dinámicos: se puede cambiar su estructura después de haberlos creado.

  • Agregar: simplemente asignamos un valor a una clave que todavía no existe.
  • Eliminar: usamos el operador delete.
const auto = { marca: "Fiat" } auto.modelo = "Cronos" // Ahora tiene dos propiedades const heroe = { nombre: "Batman", identidadSecreta: "Bruce Wayne" } delete heroe.identidadSecreta // Desaparece del objeto

Errores Comunes y Buenas Prácticas

Objetos vs Arrays

Los arrays usan [] y se basan en orden/posición. Los objetos usan {} y se basan en nombres/etiquetas.

Olvidar las Comas

Entre cada propiedad de un objeto debe haber una coma. Es una de las causas más frecuentes de errores de sintaxis.

Propiedades Inexistentes

Acceder a una propiedad que no existe no da un error fatal: JavaScript devuelve undefined.

const No es Inmutable

Con const podés modificar propiedades internas. Lo que no podés hacer es reasignar la variable a un objeto nuevo.

¿Qué es un Constructor?

El Molde

Un constructor es como un molde o un plano de construcción: define la forma del objeto, pero no es el objeto en sí.

  • Técnicamente es una función, pero su nombre suele empezar con Mayúscula (convención).
  • Se ejecuta exclusivamente usando la palabra clave new.
  • this representa al nuevo objeto que se está creando en ese preciso momento.
function Auto(marca, modelo) { this.marca = marca // El objeto tendrá esta marca this.modelo = modelo // El objeto tendrá este modelo }

El Operador new: El Botón de Encendido

4 Pasos Automáticos

Cuando usás new, JavaScript realiza cuatro pasos automáticos:

  • Crea un nuevo objeto vacío.
  • Vincula this a ese nuevo objeto.
  • Ejecuta el código de la función constructora.
  • Devuelve automáticamente el nuevo objeto creado.
const miAuto = new Auto("Toyota", "Corolla") // miAuto ahora es: { marca: "Toyota", modelo: "Corolla" }

Instancias: Los "Hijos" del Molde

Independencia de Datos

Cada objeto creado a partir de un constructor se llama instancia.

  • persona1 y persona2 comparten la misma estructura (el mismo molde)...
  • ...pero sus datos son independientes: cambiar persona1 no afecta a persona2.
  • La función constructora ya casi no se usa: su rol fue absorbido por las clases (class).
function Persona(nombre, edad) { this.nombre = nombre this.edad = edad } const persona1 = new Persona("Julieta", 27) const persona2 = new Persona("Martín", 31)

¿Qué es una Clase en JavaScript?

Analogía

Pensá en una clase como el plano de una casa: define ventanas, puertas y paredes, pero no podés vivir dentro de un plano.

  • Para tener algo real hay que construir la casa usando ese plano.
  • Ese proceso se llama instanciación, y el resultado es el objeto o instancia.
  • Introducidas en ES6 (2015): no cambiaron cómo funciona JS por dentro, pero sí cómo organizamos el código.

Estructura de una Clase: constructor() y Métodos

Sintaxis

Se declara con la palabra clave class. Por convención, el nombre empieza con Mayúscula (PascalCase).

  • constructor(): se invoca automáticamente con new Usuario(...); usa this para inicializar propiedades.
  • Métodos: funciones que viven dentro de la clase, sin function ni =>.
class Usuario { constructor(nombre, email, edad) { this.nombre = nombre this.email = email this.edad = edad } saludar() { console.log("Hola, soy " + this.nombre) } } const usuario1 = new Usuario("Ana", "ana@example.com", 25) usuario1.saludar()

El Error Más Común: Olvidar el new

#FindTheBug

Con funciones comunes, olvidar el new a veces genera errores silenciosos. Con las clases, JavaScript es mucho más estricto.

  • Las clases están protegidas: siempre hay que usar la palabra clave new.
class Animal {} // Error frecuente const miPerro = Animal() // TypeError: Class constructor Animal cannot be invoked without 'new' // Correcto const miPerro2 = new Animal()
