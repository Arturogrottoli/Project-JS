El DOM: la Representación del Documento

Analogía

Imaginá que tu página HTML es una mansión y JavaScript es un robot que vive en ella. Para pintar una pared de rojo, primero tiene que saber dónde está esa pared.

  • El DOM (Document Object Model) es una representación interna de la página en forma de árbol.
  • El tronco es el documento entero (document); de ahí nacen <head> y <body>; y de <body>, ramas más chicas como <h1>, <p>, <div>.
  • Gracias al DOM, JavaScript puede "ver" el HTML como un objeto: acceder a sus propiedades y métodos para cambiar contenido, colores o comportamiento en tiempo real.

Nodos vs. Elementos: ¿Qué Estamos Buscando?

Nodo

Es el término más amplio. Un comentario en tu código, el texto dentro de un párrafo, o una etiqueta HTML: todos son nodos.

Elemento

Es un tipo específico de nodo que corresponde directamente a una etiqueta HTML, como <div>, <a> o <button>.

Selectores CSS: El Mapa de Búsqueda

Etiqueta

Busca por el nombre de la etiqueta. Ejemplo: h1, p, button.

Clase

Busca elementos con un atributo class. Se escribe con un punto inicial. Ejemplo: .btn-principal.

ID

Busca un elemento único con un atributo id. Se escribe con un numeral. Ejemplo: #header.

getElementById(): El Tiro de Precisión

Sintaxis Core

document.getElementById() es la forma más directa y rápida de encontrar un elemento.

  • Funciona como un número de seguridad social: solo debería haber UN elemento con ese ID en toda la página.
<h1 id="titulo-principal">¡Hola, Mundo!</h1> const titulo = document.getElementById("titulo-principal") console.log(titulo) // Muestra el <h1> en la consola

querySelector(): La Navaja Suiza

El Más Moderno

A diferencia de getElementById, acepta CUALQUIER selector CSS válido: "buscame el primer elemento que cumpla esta regla".

  • Combinadores: document.querySelector("nav > ul > li > a").
  • Ojo: devuelve SOLO el primer elemento que coincide, aunque haya 10 que cumplan la condición.
// Por clase const boton = document.querySelector(".btn-cancelar") // Por etiqueta const parrafo = document.querySelector("p")

Agrupando Elementos: Dos Formas de Buscar Varios

getElementsByClassName()

Agrupa todos los elementos con la misma clase. Funciona como un array, aunque técnicamente su nombre es "colección de elementos HTML".

querySelectorAll()

El método más moderno para agrupar: acepta CUALQUIER selector CSS válido (no solo clases). Técnicamente devuelve una "lista de nodos" (NodeList).

El Valor de null

Buenas Prácticas

Si buscás un elemento que no existe (ID mal escrito, clase que no está), los métodos de selección te devuelven null.

  • Consejo: siempre que selecciones algo, hacé un console.log para asegurarte de que no obtuviste null.
  • Si recibís null y después intentás cambiarle algo a ese elemento, tu código va a romperse en el siguiente paso.
const boton = document.querySelector("#no-existe") console.log(boton) // null boton.textContent = "Hola" // TypeError: Cannot set properties of null

Encontrá el Error en los Selectores

#FindTheBug

Este código tiene DOS errores de selección. El HTML tiene id="titulo" e id="listado". ¿Los encontrás?

  • querySelector("titulo") busca la ETIQUETA <titulo> (que no existe): faltaba el numeral, "#titulo".
  • querySelector(".listado") busca por CLASE: como es un id, faltaba el numeral en vez del punto, "#listado".
function cargarDOM() { const titulo = document.querySelector("titulo") const listado = document.querySelector(".listado") titulo.innerText = "www.mandafruta.com" // ... } // ❌ titulo y listado van a ser null

Errores Comunes y Buenas Prácticas

Repetir IDs

Aunque el navegador a veces lo permita, los IDs deben ser únicos. Si repetís uno, getElementById solo encuentra el primero, y tu HTML deja de ser válido.

querySelector vs. querySelectorAll

Si necesitás atrapar TODOS los elementos de una lista (ej: todos los <li>), querySelector no te sirve: solo trae el primero. Para eso existe querySelectorAll.

textContent: Cambiar el Texto, de Forma Segura

Simplicidad y Seguridad

Cuando querés cambiar las palabras que aparecen dentro de un elemento, la herramienta más segura es textContent.

  • Simplicidad: solo maneja texto plano.
  • Seguridad: si intentás insertar etiquetas HTML, las va a mostrar literalmente como texto, en vez de ejecutarlas.
const titulo = document.querySelector('h1') titulo.textContent = "¡Hola, mundo dinámico!"

innerHTML: Cambiar Contenido CON Etiquetas

Más Flexible

Cuando querés cambiar el contenido incluyendo etiquetas HTML (como <strong> o <img>), usás innerHTML.

  • Permite insertar HTML directamente, y sirve para crear estructuras dinámicas: listas, tarjetas, botones.
  • Diferencia clave: a diferencia de textContent, innerHTML SÍ interpreta las etiquetas (cuidado con el riesgo de inyección de código).
const titulo = document.querySelector('h1') titulo.innerHTML = "<strong>¡Hola, mundo dinámico!</strong>" // El texto aparece en negrita: <strong> sí se interpreta

createElement(): Crear Elementos desde Cero

Contenido Dinámico

Cuando querés crear un elemento HTML NUEVO desde JavaScript (un <p>, un <div>, un <button>), usás createElement.

  • Permite generar elementos dinámicamente, cuando la página ya está cargada.
  • Muy útil para tarjetas, listas o contenido generado automáticamente.
const parrafo = document.createElement('p') parrafo.textContent = "Este párrafo fue creado con JavaScript" document.body.appendChild(parrafo) // se añade el <p> al final del body

remove(): Eliminar Elementos del DOM

Interfaces Dinámicas

Cuando querés eliminar un elemento HTML de la página, la herramienta más usada es remove().

  • Simplicidad: elimina el elemento directamente, sin necesidad de acceder al elemento padre.
  • Código más limpio que métodos antiguos como removeChild().
const titulo = document.querySelector('h1') titulo.remove() // Se elimina del DOM

¿Qué es un Evento?

Fundamentos

Un evento es, simplemente, algo que sucede en el navegador: mover el mouse, presionar una tecla, que la página termine de cargar.

  • Mouse: click, dblclick, mousemove.
  • Teclado: keydown, keyup.
  • Formulario: submit, change, focus.

La Anatomía de addEventListener

Sintaxis Core

La forma moderna y recomendada de manejar interactividad.

  • El evento click ejecuta una acción cuando el usuario hace clic sobre un elemento: uno de los más usados en JavaScript.
elemento.addEventListener('tipoDeEvento', funcionAejecutar) const boton = document.querySelector('button') boton.addEventListener('click', () => { console.log('Hiciste clic') })

Ejemplo Real: El Botón de "Me Gusta"

Sin Paréntesis

Es vital notar que NO escribimos manejarClick(). Pasamos el NOMBRE de la función, sin paréntesis.

  • Con paréntesis (): la función se ejecuta YA, apenas carga la página.
  • Sin paréntesis: le das al navegador la "receta" para que la ejecute solo cuando ocurra el clic.
// 1. Seleccionamos el elemento const botonLike = document.querySelector('#btn-like') // 2. Definimos qué pasará function manejarClick() { botonLike.textContent = "¡Te gusta esto!" } // 3. Conectamos el evento botonLike.addEventListener('click', manejarClick)

Evento de Teclado: keydown

Interacción con Teclado

keydown ejecuta una acción cuando el usuario presiona una tecla: uno de los más usados para detectar escritura.

const input = document.querySelector('input') input.addEventListener('keydown', () => { console.log('Tecla presionada') })

El Objeto Event: El Mensajero con Información

event.target / event.key

Cuando ocurre un evento, el navegador no solo ejecuta tu función: le manda un "regalo", el objeto Event.

  • event.target te dice EXACTAMENTE qué elemento recibió el evento.
  • event.key te dice el nombre exacto de la tecla presionada.
document.addEventListener('keydown', function(event) { if (event.key === 'ArrowUp') { console.log("Moviendo al personaje hacia arriba...") } })

Errores Comunes y Confusiones

"No Encuentra mi Elemento"

Buscar un elemento antes de que la página termine de cargar. Solución: usar el atributo defer en la etiqueta <script>.

Evento vs. Manejador

El evento (ej: click) es la CAUSA; el manejador (handler, la función) es la CONSECUENCIA. No son lo mismo.

El DOM es un Objeto

event.target es un objeto: podés acceder a .style, .id, .className, .value. No es una cadena de texto.
