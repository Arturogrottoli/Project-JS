El Concepto de Abstracción

Analogía

Imaginá una máquina de café: para un capuchino solo apretás un botón. No necesitás saber la temperatura del agua ni la presión de la bomba.

  • Abstracción: ocultar los detalles complejos de la implementación para pensar en QUÉ hace una solución, no en CÓMO lo hace.
  • Cuando usás sumar(10, 5), confiás en el nombre de la función sin pensar en los operadores internos.
  • Reduce la complejidad (pensamos en piezas chicas) y facilita el mantenimiento: si el "cómo" cambia, el resto del programa sigue usando el mismo "botón".

Funciones que Retornan Funciones

Pattern Factory

Si una función puede retornar un valor, y las funciones SON valores, entonces una función puede retornar otra función.

  • Imaginá que querés crear distintos tipos de multiplicadores.
  • crearMultiplicador es la función "externa"; la que retorna es la función "interna" que hace el trabajo real.
function crearMultiplicador(factor) { // Función interna: hace el trabajo real return (numero) => numero * factor } const duplicar = crearMultiplicador(2) const triplicar = crearMultiplicador(3) console.log(duplicar(10)) // 20 console.log(triplicar(10)) // 30

¿Cómo es Posible? El Concepto de Closure

La Magia

La función interna sigue usando la variable factor, aunque crearMultiplicador ya haya terminado de ejecutarse.

  • Un closure es cuando una función "recuerda" el entorno donde fue creada, aunque ese entorno ya haya dejado de ejecutarse.
  • Por eso cada función fabricada tiene su propia "mochila" con esa variable, sin pisarse entre sí.
// duplicar "recuerda" factor = 2 // triplicar "recuerda" factor = 3 // Aunque crearMultiplicador() ya terminó // de ejecutarse hace rato. console.log(duplicar(5)) // 10 console.log(triplicar(5)) // 15

Funciones que Reciben Otras Funciones: Callbacks

Delegación

Así como una función puede retornar otra, también puede recibir una función como parámetro: a esto se lo llama callback.

  • La función "delegada" recibe otra función para decidir qué hacer más adelante.
  • Evita escribir duplicarNumero(), cuadradoNumero(), triplicarNumero()... una sola función genérica alcanza.
function procesarNumero(numero, accion) { return accion(numero) } const duplicar = (n) => n * 2 const cuadrado = (n) => n * n console.log(procesarNumero(5, duplicar)) // 10 console.log(procesarNumero(5, cuadrado)) // 25

forEach(): Recorrer sin Escribir un for

Punto de Partida

Muy similar al for...of: forEach() ejecuta una función una vez por cada elemento del array.

  • Es la forma más moderna y clara de iterar arrays que usar un for tradicional.
  • Este va a ser nuestro array de partida para toda la sección.
const productos = [ { nombre: "Laptop", precio: 800, categoria: "Electronics" }, { nombre: "Teclado", precio: 50, categoria: "Electronics" }, { nombre: "Silla Gamer", precio: 200, categoria: "Furniture" }, { nombre: "Monitor", precio: 300, categoria: "Electronics" }, { nombre: "Escritorio", precio: 150, categoria: "Furniture" } ] productos.forEach((producto) => console.log(producto))

find(): Buscar UN Elemento

Búsqueda Puntual

find() devuelve el PRIMER elemento del array que cumple una condición.

  • Si ningún elemento cumple la condición, devuelve undefined.
  • Devuelve el objeto en sí, no un array.
const resultado = productos.find( (producto) => producto.nombre === "Monitor" ) console.log(resultado) // { nombre: "Monitor", precio: 300, categoria: "Electronics" }

filter(): Quedarte con Varios

Nuevo Array Filtrado

filter() crea un NUEVO array con todos los elementos que cumplen una condición.

  • A diferencia de find, siempre devuelve un array (puede estar vacío).
  • Ideal para "quedarte solo con lo que sirve".
const resultado = productos.filter( (producto) => producto.precio >= 300 ) console.log(resultado) // [{ nombre: "Monitor", precio: 300, ... }, // { nombre: "Laptop", precio: 800, ... }]

some(): ¿Existe Al Menos Uno?

Devuelve Booleano

some() comprueba si AL MENOS UN elemento del array cumple una condición.

  • Devuelve true o false, nunca el elemento en sí.
  • some responde sí/no; find te da el elemento (o undefined).
const existe = productos.some( (producto) => producto.nombre === "Laptop" ) console.log(existe) // true

El Concepto de Inmutabilidad

Métodos que Modifican

push, pop, splice... cambian el array original. Si lo consultás después, ya no es el mismo.

Métodos Inmutables

map, filter y reduce NO cambian tus datos originales: generan un resultado nuevo, basado en ellos. Esto hace tu código mucho más predecible.

map(): La Línea de Traducción

Transforma

map() transforma cada elemento del array en algo nuevo.

  • Entrada: un array de N elementos.
  • Salida: un nuevo array de exactamente N elementos, transformados.
const preciosUSD = [10, 20, 30] const preciosARS = preciosUSD.map( precio => precio * 900 ) // Resultado: [9000, 18000, 27000]

reduce(): La Caja de Empaque

El Más Potente

reduce() combina todos los elementos del array en un ÚNICO valor.

  • Necesita una función con un acumulador (resultado parcial) y el valor actual.
  • Necesita un valor inicial para el acumulador.
const numeros = [5, 5, 10] const total = numeros.reduce( (acc, num) => acc + num, 0 ) // Proceso: 0+5=5 -> 5+5=10 -> 10+10=20 // Resultado: 20

Errores Comunes: #FindTheBug

#FindTheBug

Estos errores son clásicos al usar callbacks con llaves {}. ¿Los encontrás?

  • Si usás llaves {} en una función flecha, hay que escribir return explícitamente. Si no, la función devuelve undefined.
  • En reduce, omitir el valor inicial puede "funcionar por accidente", pero en arrays de objetos casi siempre rompe: acostumbrate a ponerlo siempre.
// 1) filter: olvidó el return cursos.filter((curso) => { curso.precio > 20000 }) // ❌ resultado inesperado // 2) map: olvidó el return fahrenheitTemps.map((f) => { (f - 32) * 5 / 9 }) // ❌ array lleno de undefined // 3) reduce: sin valor inicial productos.reduce((acc, p) => acc + p.precio) // ❌ riesgo de NaN, según el primer elemento

Extra: sort() para Ordenar un Array

Bonus

sort() ordena los elementos de un array según el criterio que le pases en una función de comparación.

  • (a, b) => a - b ordena de menor a mayor.
  • (a, b) => b - a ordena de mayor a menor.
  • Ojo: a diferencia de map/filter/reduce, sort() SÍ modifica el array original.
const numeros = [40, 1, 5, 200] numeros.sort((a, b) => a - b) console.log(numeros) // [1, 5, 40, 200]
