El Web Storage: El Armario del Navegador

Analogía

Cada vez que refrescamos el navegador, JavaScript "nace de nuevo": las variables (let/const) vuelven a su estado inicial.

  • Tu app es como una oficina: las variables son papeles sobre el escritorio, que se limpian cada noche.
  • El Web Storage es un armario de etiquetas: guardás cajas con información y las encontrás donde las dejaste.
  • Funciona con Clave y Valor (key/value): la clave es la etiqueta, el valor es lo que hay adentro.

localStorage vs. sessionStorage

localStorage: Memoria a Largo Plazo

No tiene fecha de expiración. Sobrevive a refrescar la página, cerrar la pestaña y hasta apagar la computadora. Ideal para: preferencias de tema, nombre de usuario, carrito de compras.

sessionStorage: Memoria de la Pestaña Actual

Efímero: solo existe mientras la pestaña esté abierta (sobrevive a un refresh, pero no a cerrarla). Es único por pestaña. Ideal para: datos temporales de un formulario de varios pasos.

Guardar y Recuperar Datos

El Set de Herramientas

Usamos localStorage en los ejemplos, pero funciona exactamente igual para sessionStorage.

  • setItem(key, value): le decimos el nombre de la "etiqueta" y el "contenido".
  • getItem(key): si la clave no existe, devuelve null.
localStorage.setItem('nombreUsuario', 'Ana García') localStorage.setItem('tema', 'oscuro') const nombre = localStorage.getItem('nombreUsuario') console.log(nombre) // 'Ana García' const edad = localStorage.getItem('edad') console.log(edad) // null: la clave 'edad' no existe

El Problema de los Objetos

#FindTheBug

El Web Storage solo guarda strings. Si intentás guardar un objeto directamente, ocurre algo frustrante.

  • JavaScript intenta convertir el objeto a texto de forma automática, y el resultado genérico no sirve de nada.
const usuario = { nombre: 'Luis', puntos: 100 } localStorage.setItem('datosUsuario', usuario) console.log(localStorage.getItem('datosUsuario')) // "[object Object]" -> ¡los datos se perdieron!

Serialización con JSON.stringify()

Objeto → Texto

"Serializar" significa convertir un objeto o array en texto plano, para poder enviarlo o guardarlo.

const usuario = { nombre: 'Luis', puntos: 100 } // Convertimos el objeto en un string de texto const usuarioJSON = JSON.stringify(usuario) localStorage.setItem('datosUsuario', usuarioJSON) // Ahora se guarda: '{"nombre":"Luis","puntos":100}'

Deserialización con JSON.parse()

Texto → Objeto

Cuando recuperamos ese texto, necesitamos convertirlo de nuevo en un objeto real para acceder a sus propiedades.

const datosDesdeStorage = localStorage.getItem('datosUsuario') // Convertimos el texto de vuelta a un objeto real const usuarioCargado = JSON.parse(datosDesdeStorage) console.log(usuarioCargado.nombre) // 'Luis'

Mejores Prácticas y Recomendaciones

Límites de Seguridad

Nunca guardes contraseñas, tarjetas de crédito o información sensible. Cualquier script malicioso puede leer estos datos fácilmente. El Web Storage no es una caja fuerte: es un armario abierto.

Capacidad Limitada

Tenés unos 5MB-10MB aproximadamente. Es mucho para texto, pero si intentás guardar imágenes o bases de datos gigantes, el navegador tira un error QuotaExceededError.

Operador Ternario (?): Acceso sin Miedo

if...else en una Línea

Simplifica una estructura condición → caso 1 → caso 2. Consta de tres partes: condición, caso si es true, caso si es false.

  • condicion ? caso1 : caso2
  • Ideal para condiciones y casos simples.
// Sin ternario let temperatura = 31 if (temperatura > 30) { console.log("Día caluroso!") } else { console.log("Día agradable") } // Con ternario temperatura > 30 ? console.log("Día caluroso!") : console.log("Día agradable")

Return Implícito: && y ||

Operadores Lógicos

El ternario y los operadores lógicos ofrecen un return implícito: no solo ejecutan la instrucción, la retornan.

  • Con &&: solo ejecuta lo de la derecha si la condición es true.
  • Con ||: usa el valor de la derecha si el de la izquierda es "falsy" (ej: null).
// AND: mensaje solo si el carrito está vacío carrito.length === 0 && console.log("El carrito está vacío!") // OR: valor por defecto si no hay nada guardado const carrito = JSON.parse(localStorage.getItem('carrito')) || []

Spread (...): Desparramar un Array

Operador Spread

El spread permite "desparramar" un array: en vez de enviarlo entero, envía cada elemento por separado.

const nombres = ["Juan", "Julieta", "Carlos"] console.log(nombres) // ["Juan", "Julieta", "Carlos"]: 1 parámetro (el array) console.log(...nombres) // Juan Julieta Carlos: 3 parámetros individuales

Spread de Objetos: Copiar y Modificar

... Dentro de {}

Nos permite listar todas las propiedades de un objeto y luego modificar o agregar las que queramos.

  • No puede haber dos propiedades con el mismo nombre: prevalece la última declarada.
const usuario1 = { nombre: "Juan", edad: 24, curso: "Javascript" } const usuario2 = { ...usuario1 } // { nombre: 'Juan', edad: 24, curso: 'Javascript' } const usuario3 = { ...usuario1, curso: "ReactJS", email: "juan@doe.com" } // { nombre: 'Juan', edad: 24, curso: 'ReactJS', email: '...' }

Rest Parameters: Parámetros Indeterminados

...numeros

El spread también se usa al declarar una función, para recibir una cantidad indeterminada de parámetros, agrupados en un array.

function sumar(...numeros) { return numeros.reduce((acc, n) => acc + n, 0) } console.log(sumar(4, 2)) // 6 console.log(sumar(10, 15, 30, 5)) // 60

Desestructuración de Arrays

Por Posición

Permite guardar elementos de un array en variables individuales, de una sola vez.

  • Cada variable toma la posición correspondiente del array.
const frutas = ['manzana', 'banana', 'pera'] const [fruta1, fruta2, fruta3] = frutas console.log(fruta1) // "manzana" console.log(fruta2) // "banana"

Desestructuración de Objetos

Por Nombre

Permite declarar variables donde guardar propiedades de un objeto, de forma rápida y directa.

  • Los nombres de las variables deben coincidir EXACTAMENTE con los nombres de las propiedades.
const usuario = { nombre: "John Doe", edad: 32 } const { nombre, edad } = usuario console.log(nombre) // "John Doe" console.log(edad) // 32

Desestructuración Anidada

Objetos Dentro de Objetos

Si una propiedad es a su vez un objeto, podemos desestructurar propiedades más internas siguiendo el mismo patrón.

const usuario = { nombre: "John Doe", telefono: { cel: 113334444, trabajo: 113325555 } } const { nombre, telefono: { trabajo } } = usuario console.log(nombre) // "John Doe" console.log(trabajo) // 113325555

Alias: Renombrar al Desestructurar

propiedad: nuevoNombre

A veces los nombres de las propiedades no son muy descriptivos: podemos desestructurar con un alias, un nombre alternativo.

const item = { item_id: 432, product_name: "Some product", price_per_unit: 5600 } const { item_id: id, product_name: nombre, price_per_unit: precio } = item console.log(id, nombre, precio) // 432 'Some product' 5600

Desestructuración en Parámetros

Directo en la Función

Si una función recibe un objeto por parámetro, se puede desestructurar directamente en la declaración.

const producto = { id: 10, nombre: "Curso Javascript", precio: 12500 } const desestructurar = ({ id, nombre }) => { console.log(id, nombre) } desestructurar(producto) // 10 Curso Javascript
